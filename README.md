# fundamentals

Systems fundamentals lab. The Python parts live under [`python/`](python/README.md): LRU/TTL cache and token-bucket and sliding-window rate limiters, each with tests, a benchmark and failure-injection switches. Retry with backoff and an idempotent job queue are the next milestone.

[`exercises/`](exercises/README.md) is a separate folder for the owner's hand-written rate limiter and LRU/TTL cache; the rule there is that AI reviews but never writes the code.
